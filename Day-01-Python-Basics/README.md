## Practical Exercise: Basic FASTA Parser

As a small bioinformatics-oriented exercise, I implemented a basic FASTA parser using Python.

**Input:**

```text
>seq1
ATGCTGT
>seq2
GGGAAA
```

**Expected output:**

```python
{
    "seq1": "ATGCTGT",
    "seq2": "GGGAAA"
}
```

This exercise demonstrates how Python strings, loops, conditional statements, and dictionaries can be combined to process biological sequence data.
